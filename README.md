## Overview

Country Hangman Search is a web game utility built around hangman puzzles that use country names as answers. At its core sits a searchable collection of countries that players can query while working out a solution, checking spellings, or drilling name recognition.

All country data ships inside the application itself, and the project is meant to be served on the web. Development attention goes mainly to the searchable dataset and the practice experience, while GitHub Pages serves as one hosting route.
